## 中文

这是一个用于 **Windows** 的 Python 小工具，主要功能如下：

- 点击指定屏幕坐标
- 在指定位置自动输入文本
- 从剪贴板读取内容并输入
- 查看当前鼠标坐标
- 提供一个简单的交互菜单

## 适用场景

- **绕过禁止粘贴的平台**：头歌、学习通、部分在线考试系统等禁用了 `Ctrl+V`，本工具通过模拟逐字键盘输入（非粘贴操作）实现内容录入
- 重复性文本录入
- 向固定位置快速输入内容
- 从剪贴板批量填充文本
- 临时查看鼠标坐标

## 运行环境

- Windows 系统
- Python 3.10+（建议）

> 说明：脚本通过 `ctypes` 调用 Windows API，不支持 macOS / Linux。

## 快速开始

### 方式一：双击运行

直接双击 `type_to_position.py`，会进入交互菜单。

脚本启动时会尝试把控制台窗口固定为 **宽 20、高 30**，方便查看菜单和坐标输出。

### 方式二：命令行运行

在 PowerShell 或 CMD 中切换到项目目录后执行：

```bash
python type_to_position.py [参数]
```

## 交互菜单

双击运行后会看到菜单：

```text
1：输入指定文本到指定坐标
2：从剪贴板输入到指定坐标
3：查看当前鼠标坐标
```

### 菜单交互说明

- 选择 `1` 或 `2` 后，程序会执行输入操作，完成后自动返回菜单
- 在选择 `1` 或 `2` 的输入过程中按 `Ctrl+C`，会直接取消并返回菜单
- 选择 `3` 后会进入鼠标坐标监视界面
- 在功能 3 中按 `Enter`，会退出监视并返回菜单，同时保留当前鼠标坐标
- 如果已经保留了上次坐标，再次选择 `1` 或 `2` 时会自动复用该坐标，不需要重复输入 X、Y

### 推荐操作流程

1. 先选择 `3` 查看鼠标坐标
2. 找到目标位置后按 `Enter`
3. 回到菜单后直接选择 `1` 或 `2`
4. 输入内容后即可执行，无需再次输入坐标

这个流程适合频繁在同一个位置执行输入的场景。

### 模式 1：输入指定文本到指定坐标

输入文本、目标 X 坐标、目标 Y 坐标后，脚本会先点击目标位置，再开始输入。

执行完成后会自动回到功能菜单，方便继续选择其他功能。

在输入内容或坐标时按 `Ctrl+C`，也会直接返回功能菜单。

如果你刚刚使用过功能 3 保存了鼠标坐标，功能 1 会直接复用该坐标。

### 模式 2：从剪贴板输入到指定坐标

输入目标坐标后，脚本会读取系统剪贴板中的文本并输入。

执行完成后会自动回到功能菜单，方便继续选择其他功能。

在输入坐标时按 `Ctrl+C`，也会直接返回功能菜单。

如果你刚刚使用过功能 3 保存了鼠标坐标，功能 2 会直接复用该坐标。

### 模式 3：查看当前鼠标坐标

程序会持续输出当前鼠标位置，移动鼠标即可刷新。

按 `Enter` 会返回功能菜单，并保留当前鼠标坐标，方便后续直接用于功能 1/2。

按 `Ctrl+C` 退出。

退出后会自动回到功能菜单，你可以继续选择其他功能。

### 交互示例

```text
1. 选择 3 查看鼠标位置
2. 把鼠标移动到目标输入框
3. 按 Enter 返回菜单
4. 选择 1 输入固定文本，或选择 2 从剪贴板输入
5. 程序自动复用刚才保存的坐标并执行
```

## 命令行参数

### 1. 普通模式

```bash
python type_to_position.py "你好" 500 300
```

含义：

- `你好`：要输入的文本
- `500 300`：目标坐标

### 2. 剪贴板模式

```bash
python type_to_position.py --clipboard 500 300
```

含义：

- 从剪贴板读取文本
- 输入到坐标 `500, 300`

### 3. 仅显示鼠标坐标

```bash
python type_to_position.py --show-mouse
```

### 4. 只输入，不点击

```bash
python type_to_position.py --no-click "测试文本" 400 250
```

适合目标窗口已经激活，只需要直接输入的场景。

### 5. 调整点击后等待时间和输入速度

```bash
python type_to_position.py --delay 0.5 --interval 0.02 "测试文本" 400 250
```

- `--delay`：点击后开始输入前等待的秒数，默认 `1.0`
- `--interval`：逐字输入间隔秒数，默认 `0.01`

## 坐标说明

- 坐标以屏幕左上角为原点 `0,0`
- X 轴向右增大
- Y 轴向下增大

## 使用注意事项

- 目标坐标不能超出当前屏幕范围
- 建议先切换到目标应用，再执行自动输入
- 部分应用可能会拦截或限制自动输入
- 剪贴板模式下请先复制好文本内容
- 控制台窗口大小会按脚本尝试固定为 `20×30`；若系统终端策略限制，可能无法完全生效

## 技术实现

脚本通过 `ctypes` 直接调用 Windows API，不依赖第三方库：

| 功能 | 实现方式 |
|------|----------|
| 鼠标移动 | `user32.SetCursorPos` |
| 鼠标点击 | `user32.SendInput`（`MOUSEEVENTF_LEFTDOWN` + `MOUSEEVENTF_LEFTUP`） |
| 键盘输入 | `user32.SendInput`（`KEYEVENTF_UNICODE`），支持中文等 Unicode 字符 |
| 剪贴板读取 | `user32.OpenClipboard` → `GetClipboardData` → `kernel32.GlobalLock` |
| 屏幕尺寸 | `user32.GetSystemMetrics` |
| 控制台窗口 | `kernel32.SetConsoleScreenBufferSize` + `SetConsoleWindowInfo` |

点击和输入之间有可配置的延迟（默认 1 秒），用于等待目标窗口响应。逐字输入间隔默认 0.01 秒，可按需调大以适配较慢的应用。

## 实用技巧

- **先定位再输入**：用功能 3 保存坐标后，功能 1/2 会自动复用，省去每次手动输入坐标
- **快速定位输入框**：先手动把鼠标悬停在目标输入框上，再运行 `--show-mouse` 获取坐标
- **适配慢应用**：如果目标应用响应慢，加大 `--delay`（如 `2.0`）；如果输入丢字，加大 `--interval`（如 `0.05`）
- **批量操作**：写一个简单的批处理脚本，连续调用多次 `type_to_position.py` 实现自动化录入
- **不点击只输入**：用 `--no-click` 适合目标窗口已经激活、只需要直接打字的场景

## 常见问题

### 为什么双击后窗口会闪一下？

因为这是控制台程序，执行完会退出；如果运行过程中报错，也可能快速关闭。

### 为什么看不到输入内容？

请确认目标窗口已经被正确点击到，并且当前应用允许接收自动输入。

### 剪贴板模式没反应？

请先复制一段文本到剪贴板，再使用 `--clipboard` 模式。

### 能输入中文吗？

可以。脚本使用 `KEYEVENTF_UNICODE` 方式发送按键，支持中文、日文、emoji 等 Unicode 字符。

### 坐标在多显示器下准吗？

坐标以虚拟屏幕左上角为原点，多显示器环境下坐标可能为负值或超出主屏分辨率，属于正常现象。

### 为什么能在禁止粘贴的平台上使用？

头歌、学习通等平台通过 JavaScript 拦截了 `Ctrl+V` 粘贴事件，但本工具使用的是 `SendInput` API 模拟键盘逐字输入，对操作系统和目标应用来说与真人打字完全一致，不触发粘贴事件，因此不受限制。
